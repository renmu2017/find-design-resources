# 文本、加载、按钮与图像素材

核验日期：2026-10-11。下载格式、代码复制、免费浏览与复用授权分别记录；这些资源提供视觉材料，业务行为由项目实现。

## css-text-effects — CSS Text Effects

- **材料与适用**：纯 CSS 文字效果及 AI 提示，覆盖渐变、发光、故障、打字、reveal、复古显示和材质，适合短标题或局部强调。
- **入口与技术**：[图库](https://text-effects.colorion.co/)按类别/效果名查找，条目提供 CSS/Prompt 与实现说明。官网说明无需 JavaScript/依赖，使用 `--ink` 变量并提供 `prefers-reduced-motion` 处理。
- **授权与核验**：官网明确免费复制、MIT，首页/分类及入口已读取；在目标字体、中文、换行和减少动画设置下仍要预览。

## circle-loaders — Circle Loaders

- **材料与适用**：单色圆形加载与 agent 状态动画，独立 SVG 包含内部样式/关键帧，适合等待和不确定进度的视觉。
- **入口与技术**：[图库](https://circleloaders.dominikakissi.com/)有 Latitude、Scanline、Waveform 等样式，选择深浅模式后复制 SVG。可作 `<img>`、CSS 背景或 inline SVG，无 JavaScript/构建步骤，示例含减少动画媒体查询。
- **访问与授权**：完整 SVG 公开可读且官网邀请复制，本次没有找到明确标准许可，不能自行标注 MIT/CC0。产品还需自己的状态文案、停止条件或确定进度逻辑。
- **核验**：首页及内嵌 SVG 已读取；未导入项目或验证全平台渲染。

## gradient-buttons — Gradient Buttons

- **材料与适用**：渐变按钮色彩与 CSS 外观，适合确定 CTA 背景、渐变方向和 hover 方案。
- **入口与技术**：[图库](https://gradientbuttons.colorion.co/)点击样式查看 Copy code，再与现有按钮结合。原生 CSS 片段不承担按钮语义、disabled/loading/focus 状态或对比度验证。
- **访问与授权**：公开复制入口，本次未找到统一标准许可；完整片段或资源包分发须查具体声明。
- **核验**：首页和复制控件已读取，没有将其视作完整 UI 框架。

## kitbitz — Kitbitz

- **材料与适用**：手绘 SVG/透明 PNG、成套 Figma kits，适合空状态、引导、功能解释和温暖的视觉；同一页面优先保持一个 kit 的笔触/色彩。
- **入口与访问**：[素材库](https://kitbitz.art/)按 kit、主题、关键词和颜色筛选；[Getting started](https://kitbitz.art/docs/getting-started)说明格式及 Figma 使用，网页检索/下载无需账户。
- **代理使用**：[MCP](https://kitbitz.art/docs/mcp)提供公开只读检索、资产资料与下载清单；Figma 插件是独立入口，普通下载不要求安装插件。
- **授权与核验**：[License](https://kitbitz.art/docs/license)仅将**原始插图资产**列为 CC0 1.0，可改写/商用、无需署名；网站、插件、MCP 源码、配置和文档属于专有平台。主页/Getting started 已在 Chrome 读取，License/MCP 文档已读取，未复制平台代码或安装插件。

## 3dicons — 3dicons

- **材料与适用**：3D 图标和成套渲染素材，适合功能入口、空状态、说明和少量视觉强调；角度、色彩与阴影保持一致。
- **入口与技术**：[官网](https://3dicons.co/)搜索图标/集合，区分 V1 下载、在线修改和 Premium 资源。PNG/Figma/源模型等实际格式以所选包为准，渲染图片不等于可交互 3D 模型。
- **访问与授权**：官网 FAQ 将当前图标库标为 CC0，可个人/商用且无需署名；首页同时有 Free/Premium 标签，新集合和付费资源的许可仍逐条核对。
- **核验**：首页、下载/Figma 入口及 FAQ 已读取；未下载全部素材或确认所有 Premium 集合均用同一许可。
