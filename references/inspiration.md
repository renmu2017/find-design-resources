# 风格、提示与设计规范

核验日期：2026-10-11。“适合”是基于公开页面形成的选型判断；收录数量与推广承诺不作为质量保证。可浏览不代表所有内容已取得或可直接商用。

## jiro — Jiro Build

- **材料与适用**：整页模板、Hero/功能/定价等区块的 AI 提示及部分组件代码，适合已有页面方向、希望快速形成初稿的 Web 项目。
- **入口与查找**：[资源库](https://jiro.build/components)按模板行业或区块类型筛选；[Growlio 模板](https://jiro.build/templates/agency/smm-agency-landing-page-growlio)可见详情与 Copy Prompt 控件。首页区分 Free/Premium；本次没有取得完整模板提示或验证生成结果。
- **技术与访问**：网站定位于 AI 网站构建工具，实际代码栈逐条确认。[官方 MCP](https://jiro.build/mcp)支持 OAuth 登录，另有浏览器扩展；完整内容受账户、套餐和当前限额影响。
- **授权与限制**：[条款](https://jiro.build/terms-conditions)允许依适用套餐为自己或客户制作最终网站/应用，禁止自动抓取、资源镜像、独立模板包/组件库再分发及竞争性用途。本 Skill 只保存入口与研究摘要。
- **核验**：[首页](https://jiro.build/)、模板、MCP 和条款已读取；大体积资源库未被文本工具完整提取。

## minimal-gallery — Minimal Gallery

- **材料与适用**：精选真实网站，适合官网、品牌、作品集、排版、留白和页面节奏。收录网站的实际功能实现需另查。
- **入口与查找**：[首页](https://minimal.gallery/)支持搜索与行业/站点类型、平台筛选；如 [SaaS 分类](https://minimal.gallery/tag/saas/)。打开相关案例，再进入原站观察桌面与手机表现。
- **访问与授权**：公开图库可读；Templates、Tools 是另外的目录，模板价格和许可按原提供方确认。截图、字体、文案与品牌资源没有因被收录而获得复用许可。
- **核验**：首页分类与 SaaS 页已读取。图库本身不提供统一组件包或所有案例的生成提示。

## kage — Kage

- **材料与适用**：真实产品截图、页面/组件分析与提示，把喜欢的设计转成可解释的实现方向，适合整页结构与局部定价、导航、空状态等参考。
- **入口与查找**：[首页](https://kage.design/)按页面、组件、行业、风格、颜色和站点栈筛选；实例：[Intercom 定价](https://kage.design/component/intercom-pricing-table)、[Intercom 整页](https://kage.design/designs/intercom-landing-page)。详情含提示与参考截图链接。
- **技术与访问**：提示可适配目标项目；“栈”筛选描述被收录的网站，不证明提供其框架源码。[MCP 文档](https://kage.design/mcp-setup)提供无需账户/key 的公开读取入口。
- **授权与限制**：[条款](https://kage.design/terms)允许免费使用/改写分析和提示，包括商用、无需署名；截图、商标、文案和艺术素材属于原产品。禁止镜像或批量下载图库。
- **核验**：首页通过 Chrome 读取，实际提示详情、MCP 和条款已读取；没有实测 MCP 调用。

## refero-styles — Refero Styles

- **材料与适用**：捕获真实产品网站的颜色、排版、间距、组件规则和 `DESIGN.md`，适合把审美参考转成跨页面的主题规则。
- **入口与查找**：[首页](https://styles.refero.design/)搜索产品、风格或描述；[Vercel 示例](https://styles.refero.design/style/f24daf3a-d43f-4dec-85a9-8ac1d5148a03)提供 Preview、DESIGN.md、Tailwind v4、CSS Variables、Design Tokens 视图。
- **使用方式**：先核对预览，再挑本项目的颜色角色、字体层级和密度；CSS/Tailwind 导出与现有版本匹配后使用。[模板说明](https://styles.refero.design/design-md/design-md-template)帮助记录主动选择与未决项。
- **访问与事实边界**：公开页面可读；原品牌图片、字体和素材不因导出 tokens 而获得复用许可。[官方说明](https://styles.refero.design/design-md/ai-readable-design-systems)明确这是捕获的风格，不是品牌发布的规范。本次未确认导出材料的统一许可或完整 Refero 账户权益。

## component-gallery — The Component Gallery

- **材料与适用**：同一控件在多个设计系统中的定义、示例和使用规范，适合研究表单、对话框、表格、树、导航、分页与无障碍行为。
- **入口与查找**：[组件目录](https://component.gallery/components/)按控件名搜索；[设计系统目录](https://component.gallery/design-systems/)显示技术、代码、使用指引和无障碍资料等特征。
- **使用方式**：比较同类控件的结构与状态，选与项目平台、密度相符的原系统，再读其官方文档。目录链接不能替代源码和使用规范。
- **访问与授权**：公开目录可读；代码、Figma 文件、字体和素材分别遵循原系统许可。
- **核验**：[首页](https://component.gallery/)和两目录已读取。首页区分控件类型、设计系统和示例数量，不把“示例数”写成“设计系统数”。

## appshot — AppShot Gallery

- **材料与适用**：App Store 展示截图、应用图标与商店视觉，适合 ASO 截图、手机画面排版、标题、配色和风格参考。
- **入口与查找**：使用可访问的 [www 入口](https://www.appshot.gallery/)，按 Genre、Tone of voice、Style、Color、Typography 筛选；示例：[Developer Tools](https://www.appshot.gallery/category/developer-tools)。
- **使用边界**：展示图可能带营销文字、背景和设备模型，不能据此推断完整应用内界面、流程或未展示状态。流程参考需结合原应用实际画面。
- **访问与授权**：公开页面可读，Free/$… 主要是被收录应用的商店价格，不能当作图库会员价格；截图、图标和品牌素材的复用许可未确认。
- **核验**：www 首页及分类已读取；裸域名首次抓取失败，没有据此判断服务不可用。

## designmd — DESIGNmd

- **材料与适用**：社区分享的单文件 Markdown 设计系统，适合项目主题、视觉约束和 AI 开发上下文，不提供完整业务实现。
- **入口与查找**：[首页](https://designmd.ai/)按 minimal、dashboard、accessible、mobile-app 等标签搜索；[Genesis 条目](https://designmd.ai/chef/genesis)含可读内容与条目 License（本例 MIT）。
- **技术与访问**：适合支持 Markdown 上下文的编码工具。[CLI](https://designmd.ai/cli)与 [MCP](https://designmd.ai/mcp)搜索/标签浏览无需 key，API 内容查看、下载等操作需免费 API key；网页可见内容与 API 权限分别判断。
- **授权与使用**：[条款](https://designmd.ai/terms)按上传者选择的 MIT、CC0、CC-BY、CC-BY-SA 或自定义许可处理每份系统。不要默认全站 MIT，下载文件先与已有主题协调，不直接覆盖既有 `DESIGN.md`。
- **核验**：首页、实际条目、CLI/MCP 和条款已读取；未创建 API key、配置集成或上传文件。

- **访问与授权**：本次示例提示/HTML 公开可读且没有登录阻断；未找到明确统一代码许可，不承诺全站 MIT 或任意再分发。
